# PGB Explorer

**اکسپلورر رسمی شبکه پرشین گلف بلاکچین**

اکسپلورر PGB رابط کاربری رسمی شبکه آزمایشی پرشین گلف بلاکچین (Persian Gulf Blockchain Testnet) است که بر پایه [Polkadot.js Apps](https://github.com/polkadot-js/apps) و با هویت بصری، تنظیمات شبکه و رابط کاربری اختصاصی PGB توسعه یافته است.

این اکسپلورر امکان مشاهده اطلاعات بلاکچین، مدیریت حساب‌ها، انتقال توکن، مدیریت دارایی‌های دیجیتال، استیکینگ، حاکمیت و عملیات خزانه شبکه را متناسب با قابلیت‌های Runtime فراهم می‌کند.

[English](README.md) · [وب‌سایت رسمی](https://persiangulfchain.com) · [اکسپلورر](https://explorer.persiangulfchain.com) · [گیت‌هاب](https://github.com/PGBOfficial) · [گزارش مشکلات](https://github.com/PGBOfficial/pgb-explorer/issues)

## ورود به اکسپلورر PGB

### [ورود به اکسپلورر رسمی شبکه](https://explorer.persiangulfchain.com)

کاربران می‌توانند بدون نصب افزونه، اطلاعات عمومی بلاکچین را مشاهده کنند.

برای مدیریت حساب‌ها و امضای تراکنش‌ها، کاربران می‌توانند افزونه رسمی PGB Signer را نصب کنند.

### [دانلود مستقیم افزونه PGB Signer برای Chrome](https://github.com/PGBOfficial/pgb-signer/releases/download/v0.64.1-pgb-testnet.2/pgb-signer-release-chrome.zip)

برای مطالعه راهنمای کامل نصب افزونه و مدیریت حساب‌ها به [مستندات فارسی PGB Signer](https://github.com/PGBOfficial/pgb-signer/blob/main/README-fa.md) مراجعه کنید.

## قابلیت‌های اکسپلورر

- مشاهده زنده بلاک‌های شبکه.
- مشاهده بلاک‌های نهایی‌شده، تراکنش‌ها و رویدادها.
- مشاهده اطلاعات حساب‌ها و موجودی توکن‌ها.
- اتصال حساب‌ها از طریق PGB Signer.
- انتقال توکن بومی شبکه PGC.
- مشاهده و مدیریت دارایی‌های دیجیتال پشتیبانی‌شده.
- دسترسی به امکانات استیکینگ و نامینیشن.
- مشاهده اطلاعات ولیداتورهای شبکه.
- دسترسی به امکانات حاکمیت شبکه.
- مشاهده اطلاعات و عملیات خزانه شبکه.
- دسترسی به سایر قابلیت‌های ارائه‌شده توسط Runtime.
- انتخاب رابط کاربری تیره Midnight یا روشن Pearl.
- اتصال به شبکه از طریق آدرس عمومی RPC.

دسترسی به عملیات مختلف به قابلیت‌های Runtime، مجوزهای حساب و تنظیمات شبکه بستگی دارد.

## مشخصات شبکه آزمایشی PGB

| مشخصه | مقدار |
|---|---|
| نام شبکه | Persian Gulf Blockchain Testnet |
| آدرس RPC | `wss://rpc.persiangulfchain.com` |
| توکن بومی | PGC |
| تعداد اعشار | 18 |
| پیشوند SS58 | 42 |
| Genesis Hash | `0x723184e0d2628f7bd203c580101778cf0b3428736d617dd59699b29c14d1fb6a` |
| اکسپلورر | https://explorer.persiangulfchain.com |
| وضعیت شبکه | Testnet |

شبکه PGB به‌صورت پیش‌فرض برای پروفایل‌های جدید مرورگر انتخاب می‌شود.

پارامتر صریح `?rpc=` و آدرس‌های ذخیره‌شده قبلی مطابق رفتار نسخه اصلی اولویت دارند.

برای تغییر شبکه انتخاب‌شده، آدرس رسمی PGB را انتخاب کنید یا از لینک زیر استفاده کنید:

[اتصال مستقیم به تست‌نت PGB](https://explorer.persiangulfchain.com/?rpc=wss://rpc.persiangulfchain.com#/explorer)

برای تغییر شبکه، اطلاعات ذخیره‌شده حساب‌ها را حذف نکنید.

مشخصات و قابلیت‌های شبکه مستقیماً از بلاکچین متصل خوانده می‌شوند. اکسپلورر PGB هیچ تغییری در Runtime یا تنظیمات بلاکچین ایجاد نمی‌کند.

## راهنمای شروع استفاده

### ۱. نصب افزونه PGB Signer

فایل رسمی افزونه را دانلود کنید:

[pgb-signer-release-chrome.zip](https://github.com/PGBOfficial/pgb-signer/releases/download/v0.64.1-pgb-testnet.2/pgb-signer-release-chrome.zip)

1. فایل ZIP دانلودشده را در یک پوشه ثابت استخراج کنید.
2. مرورگر Google Chrome را باز کنید.
3. وارد آدرس `chrome://extensions` شوید.
4. گزینه **Developer mode** را فعال کنید.
5. روی **Load unpacked** کلیک کنید.
6. پوشه استخراج‌شده حاوی فایل `manifest.json` را انتخاب کنید.
7. از نمایش نام **PGB Signer** در فهرست افزونه‌ها اطمینان حاصل کنید.

### ۲. ساخت حساب تست‌نت

1. افزونه PGB Signer را باز کنید.
2. گزینه ساخت حساب جدید را انتخاب کنید.
3. یک عبارت بازیابی جدید ایجاد کنید.
4. عبارت بازیابی را به‌صورت امن و آفلاین نگهداری کنید.
5. شبکه Persian Gulf Blockchain Testnet را انتخاب کنید.
6. نام حساب و یک رمز عبور قوی تعیین کنید.
7. مراحل ساخت حساب را تکمیل کنید.

فقط از حساب‌های جدید و مخصوص تست‌نت استفاده کنید. عبارت بازیابی حساب‌های دارای دارایی واقعی یا ارزشمند را وارد نسخه آزمایشی نکنید.

### ۳. اتصال حساب به اکسپلورر

1. وارد [اکسپلورر رسمی PGB](https://explorer.persiangulfchain.com) شوید.
2. از انتخاب شبکه Persian Gulf Blockchain Testnet اطمینان حاصل کنید.
3. درخواست اتصال افزونه را بررسی کنید.
4. آدرس وب‌سایت درخواست‌کننده را بررسی کنید.
5. دسترسی به حساب‌های موردنظر را تأیید کنید.
6. وارد بخش Accounts شوید و نمایش حساب خود را بررسی کنید.

### ۴. ارسال تراکنش آزمایشی

برای انجام عملیاتی که نیازمند پرداخت کارمزد هستند، حساب باید دارای موجودی توکن آزمایشی PGC باشد.

1. عملیات موردنظر را در اکسپلورر انتخاب کنید.
2. حساب ایجادشده در PGB Signer را انتخاب کنید.
3. اطلاعات موردنیاز تراکنش را وارد کنید.
4. شبکه، مقصد، مبلغ، کارمزد تخمینی و هشدارها را بررسی کنید.
5. درخواست امضا را در PGB Signer تأیید یا رد کنید.
6. ثبت تراکنش، نهایی‌شدن و رویدادهای مرتبط را بررسی کنید.

امضای موفق به‌تنهایی به معنی اجرای موفق تراکنش نیست.

PGB Signer مسئول مدیریت کلیدهای حساب و امضای تراکنش‌ها است. اکسپلورر مسئول ارتباط با شبکه، ساخت و ارسال تراکنش‌ها است.

## ساخت اکسپلورر از سورس

### پیش‌نیازها

- Node.js نسخه 18.14 یا بالاتر
- Corepack
- Yarn نسخه 4.6.0

فایل نسخه ثابت Yarn و فایل `yarn.lock` در مخزن سورس موجود هستند.

برای اجرای تنظیمات فعلی CI از محیط Node.js 24 استفاده کنید.

### لینوکس و macOS

```sh
corepack enable
ELECTRON_SKIP_BINARY_DOWNLOAD=1 yarn install --immutable
yarn build:images
yarn build:www
```

### ویندوز PowerShell

```powershell
corepack enable
$env:ELECTRON_SKIP_BINARY_DOWNLOAD='1'
yarn install --immutable
yarn build:images
yarn build:www
```

متغیر `ELECTRON_SKIP_BINARY_DOWNLOAD` از دانلود غیرضروری نسخه دسکتاپ Electron هنگام آماده‌سازی برنامه وب جلوگیری می‌کند.

قابلیت‌ها و سورس Electron حفظ شده‌اند.

مسیر خروجی نهایی ساخت:

```text
packages/apps/build
```

### اجرای تست‌های خودکار

```sh
yarn test
```

برای مشاهده نتایج ثبت‌شده ساخت، تست‌های خودکار و محدودیت‌های محیط اجرایی، فایل [FINAL-TEST-REPORT.md](FINAL-TEST-REPORT.md) را مطالعه کنید.

ساخت موفق نرم‌افزار به معنی تأیید اجرای موفق تراکنش‌های شبکه یا عملکرد کامل تمامی ماژول‌های Runtime نیست.

## اجرای محیط توسعه

برای اجرای محیط توسعه:

```sh
yarn start
```

برای پیش‌نمایش نسخه از قبل ساخته‌شده:

```sh
node scripts/pgb-serve.cjs
```

سپس آدرس زیر را در مرورگر باز کنید:

```text
http://localhost:3000/#/explorer
```

سرور پیش‌نمایش فقط روی رابط محلی دستگاه اجرا می‌شود و برای توسعه و آزمایش در نظر گرفته شده است.

این سرور برای میزبانی عمومی و استفاده عملیاتی طراحی نشده است.

## استقرار اکسپلورر

محتویات مسیر زیر را در ریشه یک میزبان فایل ایستا با پشتیبانی از HTTPS قرار دهید:

```text
packages/apps/build
```

الزامات استقرار:

- استفاده از HTTPS برای میزبانی اکسپلورر.
- استفاده از آدرس رسمی و امن WSS شبکه.
- حفظ نام فایل‌های تولیدشده و اطلاعات یکپارچگی منابع یا SRI.
- جلوگیری از کش قدیمی فایل‌های `index.html`، `env-config.js` و `pgb-config.js`.
- امکان کش بلندمدت فایل‌های ایستا دارای هش.
- حفظ مسیرهای مبتنی بر Hash بدون نیاز به مسیریاب سمت سرور.
- حفظ تنظیمات پیش‌فرض شبکه در فایل `packages/apps/public/pgb-config.js` برای ساخت مجدد.
- خودداری از قرار دادن رمز عبور، کلید خصوصی یا اطلاعات محرمانه در تنظیمات مرورگر.

## امنیت و حریم خصوصی

اکسپلورر PGB در حال حاضر نرم‌افزار آزمایشی تست‌نت است.

از حساب‌های مخصوص تست‌نت استفاده کنید و از عبارت بازیابی، کلیدهای خصوصی و نسخه‌های پشتیبان رمزگذاری‌شده محافظت کنید.

اطلاعات ثبت‌شده روی بلاکچین عمومی هستند.

حساب‌های مدیریت‌شده توسط مرورگر و افزونه‌های مجاز، رفتار ذخیره‌سازی و امضای نسخه اصلی را حفظ کرده‌اند.

گزینه‌های سایر شبکه‌ها، لینک سرویس‌های عمومی و یکپارچه‌سازی‌های اختیاری برای حفظ سازگاری در دسترس هستند. همواره شبکه، آدرس اتصال و مقصد انتخاب‌شده را بررسی کنید.

### هشدارهای مهم امنیتی

- فقط از حساب‌های مخصوص تست‌نت استفاده کنید.
- از دارایی‌های واقعی یا ارزشمند Mainnet استفاده نکنید.
- عبارت بازیابی و کلید خصوصی خود را افشا نکنید.
- پیش از تأیید اتصال افزونه، آدرس وب‌سایت را بررسی کنید.
- تمام اطلاعات تراکنش را پیش از امضا بررسی کنید.
- PGB Signer را فقط از منابع رسمی پروژه دانلود کنید.
- اطلاعات محرمانه را در گزارش مشکلات یا لاگ‌ها منتشر نکنید.

برای مشاهده اصلاحات امنیتی ثبت‌شده، هشدارهای وابستگی‌ها و محدودیت‌های حل‌نشده، فایل [SECURITY-AUDIT.md](SECURITY-AUDIT.md) را مطالعه کنید.

موفقیت تست‌های خودکار به معنی دریافت تأییدیه مستقل امنیتی نیست.
