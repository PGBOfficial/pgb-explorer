# شروع کار / Getting started

راهنمای فعلی نصب، ساخت، تنظیم RPC و استقرار در README-fa.md و README.md است. ZIP سورس، Build آماده ندارد؛ برای اجرای بدون نصب وابستگی، ZIP جداگانه PGB-Explorer-Final-Build.zip را روی میزبان ایستا قرار دهید. هیچ کلید یا رمز را در تنظیم شبکه قرار ندهید.

The current installation, build, endpoint and deployment instructions are in README.md and README-fa.md. The Source ZIP requires a build; the separate PGB-Explorer-Final-Build.zip contains static deployment assets. Do not put keys or passwords in endpoint configuration.
